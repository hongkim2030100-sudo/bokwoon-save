# 80일의 복

매일의 신행학을 기록하고 80일의 여정을 눈으로 확인하는 작은 기록 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 기록은 브라우저의 localStorage에 저장됩니다.

## GitHub에 올리기

이 폴더를 새 GitHub 저장소에 올린 뒤 Vercel에서 해당 저장소를 Import하면 별도 서버 없이 배포할 수 있습니다. Framework Preset은 `Other`, Build Command와 Output Directory는 비워두면 됩니다. 사용자명과 저장소 주소는 GitHub와 Vercel에서 직접 정하면 됩니다.
